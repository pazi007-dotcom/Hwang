# 접수부터 완공까지 — 공사 5건, 겹치는 기간 포함 (2026-11-02 ~ 2027-01-04)

폰 앱(360폭)을 소장이 누르는 순서 그대로 조작했다. 매일 아침 홈의 발주·체크 확인, 매일 밤 집 PC와 맞추기.

## 이 시나리오에서 잡아 고친 것

| 문제 | 고침 |
|---|---|
| 집 PC가 만든 발주·체크 할 일이 폰에서 **체크가 안 됨**(오류도 안 뜸) — 내려올 때 version·done 칸이 빠짐 | 집 PC는 행 전체를 보내고, 폰은 빠진 값을 채움. 실패하면 알림 |
| 접수 체크리스트와 자동 일정에 **같은 일이 두 번**(착공 서류, 사진(전)) | 겹치면 자동 일정이 만들지 않음 |
| 발주·체크 **기한이 토·일** → 월요일에 「2일 지남」 | 모든 기한을 그 전 금요일로 (U형 개거 250m 일정 44건 중 주말 0) |
| 폰에 **공종 추가·측점 시공 기록이 없음** → 공정률·물량 발주가 안 됨 | 홈 「+ 공종 추가」, 일지 「6. 오늘 시공」(측점 시작은 어제 끝에서 이어짐), 홈·보고서에 공정률 |
| 새 U형 개거 공종이 들어와도 일정이 일반 체크로 남음 | 집 PC가 물량 기준으로 다시 계획 |
| 보고서 「일지 없는 날」에 **완공 뒤 날짜**(12/21~31)까지 셈 | 시작~완공 사이만 |
| 출역표 날짜별 「0.5 / 인」 줄 갈림 | 한 줄 |
