## 온새가 승인하지 않은 것 (영주형·바깥 확인 필요)

- 요성리 관급자재 변경과 기초 단면 변경의 **발주처(문경시) 승인** — 금액이 걸린 설계변경이고 구조 판단이다.
- D13 겹이음 "20mm" → 20d(260mm)로 계산해 두었으나 기준(약 400mm 이상)보다 짧다. 감독 확인 필요.
- 터파기 저폭: 양측 거푸집 작업 공간을 두면 약 2.62m가 필요한데 횡단면도 판독값은 약 2.2m.
- 문경시청이 사진대지를 HWPX로 받는지, 양식 원본 파일.
- 집 PC D 드라이브 상태, 한글 설치 여부 (이 세션에서는 PC에 접속되지 않았다).
- 입찰 자격 판정용 회사 정보(면허, 시공능력평가액, 실적)와 나라장터 API 이용 신청.
- 대표이사 메일 주소와 업무용 계정 만들기.
- 실제 단가(인력·장비·자재)와 협력업체 이름.
