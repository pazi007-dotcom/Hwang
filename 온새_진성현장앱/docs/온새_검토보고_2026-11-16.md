# 온새 검토 보고 — 한 달 시뮬레이션 (2026-11-16)

영주형 지시: "전달하지 말고 전체 과정을 예시로 시뮬레이션해서 다시 검토해봐."
APK는 전달하지 않았다. 아래는 폰 코드와 실제 집 PC 서버를 함께 돌린 2026년 11월 한 달 예시의 결과다.

## 2. 시뮬레이션이 잡은 문제와 조치

| # | 문제 | 영향 | 조치 | 확인 |
|---|---|---|---|---|
| 1 | 「어제와 같이」가 타설한 날의 레미콘·펌프카까지 다음 날로 복사하고, 그게 또 복사되어 쌓임 | 펌프카 4일 → **40일 30,030,000원**, 레미콘 23㎥ → **239㎥**. 결제가 크게 틀림 | 복사 전에 고르는 화면. 인력은 켬, 장비는 전날에도 쓴 것만 켬, 자재·외주는 끔 | 펌프카 4일, 레미콘 23㎥ |
| 2 | 같은 사람이 두 현장에 1공수씩 → 하루 2공수인데 경고 없음 | 인건비 두 배 지급 위험 | 저장·복사 전에 "하루 n공수입니다. 나눠 뛰었으면 0.5씩" 확인창(장비는 같은 업체·같은 기종 1일 초과 시) | 화면 시험 통과 |
| 3 | 긴급 건에 투입을 넣어도 '접수' 상태로 남음 | 진행 중 공사 알림에서 빠짐 | 첫 투입이 들어가면 자동으로 '진행' | 확인 |
| 4 | 현장 작업일을 일지 수로 셈(접수만 한 날·비 온 날 포함) | 요성리 24일로 표시(실제 21일) | 투입 있는 날 = 작업일, 작업 없음 = 쉼으로 따로 | 작업 21일 · 쉼 2일 |
| 5 | 저장 알림이 4초 동안 저장 단추를 가림(접은 화면) | 연속 입력이 막힘 | 알림 2.5초, 새 알림이 오면 이전 것은 바로 닫힘 | 화면 시험 통과 |

이번 판을 만들며 먼저 고친 것(0.1에서 실사용이 막힌 원인):

| 문제 | 조치 |
|---|---|
| 단가표가 PC에서 내려와야만 항목을 고를 수 있어 작업자·장비 입력이 막힘 | 항목·받는 곳·단가를 직접 적음. 처음 쓰는 업체·단가는 저장할 때 등록. 다음부터 추천 |
| 저장할 때마다 일지 화면이 새로 만들어져 입력칸과 **작업일이 오늘로 되돌아감** | 화면 상태 유지 (밀린 일지를 여러 줄 넣어도 날짜 유지) |
| 저장한 줄을 고치거나 지울 수 없음 | 줄을 누르면 고치기·지우기(지우기는 두 번 눌러 확인) |
| 폰에 월말 결제·한 달 집계가 없음 | 결제 탭: 받는 곳별 줄 돈, 현장별 금액, 공수·일수, 이월·지급·잔액, 현장별 한 달 집계, 카톡용 요약 복사 |
| 큰 금액이 줄바꿈되어 `11,054,00` / `0 원`으로 쪼개짐, 「현장」 글자 잘림 | 칸 안에서 글자 크기를 줄여 한 줄 유지, 위쪽 여백 |
| 인력 입력 중에 장비·자재 업체가 받는 곳으로 추천됨 | 종류별 추천 |

## 3. 숫자 대조 (고친 뒤)

| 받는 곳 | 앱 | 손 계산 |
|---|---|---|
| 박목수 팀 (형틀목공) | 9,660,000 · 42공수 | 2명 × 21일 × 230,000 |
| 대성중기 (6W·3W) | 14,160,000 · 21일, 지급 5,000,000, 잔액 9,160,000 | 6W 19.5일 + 긴급 0.5일 + 3W 1일 |
| 이영수 | 4,114,000 · 22공수 | 요성리 21 + 답사 1 |
| 김반장 | 3,927,000 · 21공수 | 요성리 20.5 + 긴급 0.5 |
| 문경펌프 | 3,030,000 · 4일 | 750,000 × 3 + 780,000(충돌에서 고른 값) |
| 가은레미콘 | 2,254,000 | 23㎥ × 98,000 |
| 한빛운수 | 846,000 | 덤프 3대 × 282,000 |
| 문경관재 | 270,000 | PE관 6m × 45,000 |
| **합계** | **38,261,000** | 일치 |

- 폰 결제 집계 = 집 PC 서버 집계 = 월말 Excel 「결제요약」: 38,261,000원, 받는 곳 8곳, 받는 곳별 금액 모두 일치. Excel 수식 오류 0.
- 견적 B는 서버에서도 지워짐, 수의 C는 '취소'로 남고 답사 인건비 187,000원은 집계에 그대로.
- 충돌 1건은 폰에서 고른 값이 서버에 반영되고 서버에 남은 충돌 0.

## 6. 다음 판 제안 (우선순위)

1. 공사 건에 사진·도면·내역 첨부(폰 카메라·파일) + 위치 기록 → 사진대지의 바탕
2. 폰에서 공종 만들기와 측점 입력 간단화
3. 한 번에 두 현장으로 나눠 넣기(0.5 + 0.5 자동)
4. 기한 알림을 휴대폰 알림창으로
5. 설명서 0.2판
