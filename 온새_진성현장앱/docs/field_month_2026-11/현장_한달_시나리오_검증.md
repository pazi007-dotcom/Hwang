대표님 메일은 실제로 보내지 않고 파일로 남겨 열어 봤다. 스크립트: `app/test/field_month/month.js`.

## 이 시나리오에서 잡아 고친 것

| 문제 | 현장에서 생기는 일 | 고침 |
|---|---|---|
| 앱을 켜 둔 채 다음 날이 되면 일지 날짜가 어제로 남음 | 오늘 입력이 어제 일지로 들어감 | 앱을 다시 열면 오늘 날짜로 |
| 수량 칸에 1이 있는 상태에서 0.5를 치면 10.5 | 김반장 하루 10.5공수 저장 (경고만 뜨고 저장됨) | 숫자 칸을 누르면 통째로 선택 + 한 사람 한 줄 2공수 넘으면 저장 안 됨 |
| 밀린 일지 날짜 고르기가 영어(Mon, Nov 23, OK) | | 한국어(11월 23일 (월), 확인) |
| 12월 초에 결제 탭을 열면 12월(빈 달)이 나옴 | 매번 ◀ 눌러야 함 | 1~10일에는 지난달이 먼저 |
| 관급자재 배정량을 폰에서 넣을 곳이 없음 | 자재 시트 관급 칸이 비어 있음 | 명부 자재 등록에 사급/관급(발주처 지급)/관급(우리가 구매) + 배정량 |
| 보낸 뒤에도 「보내기」가 살아 있음 | 두 번 보낼 수 있음 | 「보고 보냄 (12-01)」로 잠김. 일지를 고쳐 숫자가 바뀌면 「정정 보고」 |
| 출역표·자재 시트 현장 이름 잘림 | | 칸 넓힘 |
| 긴급·견적 체크리스트 4개 | 현장에서 다 못 봄 | 2개씩 |
