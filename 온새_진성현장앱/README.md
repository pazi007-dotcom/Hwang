# 온새_진성현장앱

|---|---|---|

| 6. 확장(온새 제안) | 8개 반영 | 아래 표 |

추가(11-16): 공사 건 접수→보류/취소/진행→완공→민원, 시작 예정일 기준 발주·체크 알림, 여러 현장 하루 요약,
폰 앱(Flutter, `app/`) 첫 판과 APK 빌드, 사용 설명서(`docs/온새_진성현장앱_사용설명서.pdf`).

검증 네 칸: **단위 테스트 서버 77개 + 폰 14개 + 폰↔서버 연동 1개 통과, flutter analyze 0건 / 브라우저(PC 크롬, 폰 크기 화면) 확인 / 폴드7 실기기 미확인 / 출력물은
LibreOffice 재계산만 확인(PC Excel·모바일 Excel·A4 인쇄 미확인)**.

아직 없는 것: 폰에서 줄 고치기, 기준 정보 입력 화면, 입찰 분석, 사진 촬영·공정 표지 합성, HWPX·PowerPoint 내보내기,
연보, 실제 메일 발송 시험, DWG 변환. 지금 화면은 집 PC 서버가 띄우는 웹 화면이라 **서버에 연결돼 있을 때만**
열린다. 폰 앱은 인터넷 없이 입력하고 연결되면 맞춘다(실기기 확인 전).

APK 빌드: `cd app && flutter build apk --release` (경로에 한글이 있어 `LC_ALL=C.UTF-8` 필요, 리눅스 기준).

## 온새 제안 8가지 반영 내용 (설계안 11장)

| # | 제안 | 구현 | 파일 |
|---|---|---|---|
| 1 | 측점을 모든 기록의 주소로 | 측점 구간별 기록 모아 보기, 공정 막대 | `stations.py` |
| 2 | 문서는 언제나 다시 만든다 | 보고서는 매번 원본에서 생성, 요약은 상세를 더한 수식 | `excel_report.py` |
| 3 | 월말 마감 잠금 | 전송 성공 시 잠금, 이후 수정은 사유·이력, 정정본 | `store.py`, `mailer.py` |
| 4 | 설계변경 근거 자동 축적 | 설계·실행 수량 5% 이상 차이 → 측점별 사진·일지·야장 묶음 | `alerts.py` |
| 5 | 송장·명세서 사진 자동 입력 | AI 판독 → 검산 → 화면 확인 → 등록 → 일지와 대조 | `invoice_intake.py`, `invoice_reader.py` |
| 6 | 말로 쓰는 일지 | 문장 → 인력·장비·자재·측점 구간 초안 → 확인 후 저장 (인터넷 불필요) | `voice_log.py` |
| 7 | 원가 경보 | 원가 집행률이 공정률보다 10%p 이상 앞서면 경보 | `alerts.py` |
| 8 | 단가 갱신 알림 | 시장 단가와 3% 이상 벌어지면 알림(자동 변경 안 함) | `alerts.py` |

## 실행

```
cd server
python -m pip install openpyxl pytest        # 한 번만
python -m pytest -q                          # 테스트
python -m jinsung.api --demo                 # 요성리 예시 자료로 둘러보기 → http://127.0.0.1:8765
python -m jinsung.api --db D:/진성현장/jinsung.db   # 실제 사용
```

- 폰에서 쓰려면 Tailscale 주소로 `--host` 를 주고, 환경 변수 `JINSUNG_TOKEN` 을 정한다. 공유기 포트는 열지 않는다.
- 메일은 서버 환경 변수 `JINSUNG_SMTP_HOST / PORT / USER / PASSWORD` 로만 설정한다(저장소·폰에 두지 않음).
- 명세서 사진 판독은 서버에 `pip install anthropic` 과 API 자격 증명이 있어야 한다.
