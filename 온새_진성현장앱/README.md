# 온새_진성현장앱

진성현장 통합 앱. 설계 기준: 「진성현장 통합 앱 설계안 v1.0」(2026-11-15 확정).

## 지금 단계: 0. 기반

통과 기준: 폰과 PC에서 같은 현장을 만들고 동시에 고쳐도 자료가 사라지지 않음.

| 폴더 | 내용 |
|---|---|
| `server/jinsung/schema.sql` | 공통 데이터 모델 (현장 → 공종 → 측점 → 작업일 → 투입 기록) |
| `server/jinsung/store.py` | 저장·수정 규칙 (날짜, 현장 필수, 충돌, 월 마감) |
| `server/jinsung/reports.py` | 집계 (월 결제, 현장별 투입, 배정 자재 대비) |
| `server/jinsung/seed_rates.py` | 기본 단가 초안 (영주형 확인 필요) |
| `server/tests/` | 설계안 검증 계획의 고정 테스트 |

## 테스트 실행

```
cd server
python -m pytest -q
```

## 코드 파일 이름

결과물 파일은 앞에 "온새"를 붙이지만, 코드 안의 파일(모듈)은 프로그램이 불러올 수 있도록
영문 이름을 쓴다. 프로젝트 폴더 이름에 "온새_"를 붙였다.
